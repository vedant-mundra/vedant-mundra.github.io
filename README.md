# Personal Profile Website

A responsive one-page profile built with HTML and CSS.

## Files
- `index.html`: page content
- `css/style.css`: all styling (colours and fonts are at the top)
- `images/profile.svg`: placeholder photo; replace with your own

## Customise
1. Replace "Your Name" and all sample text in `index.html`.
2. Add your photo as `images/profile.jpg` and change the `<img src>` to `images/profile.jpg`.
3. Update the email, phone, GitHub and LinkedIn links in the Contact section.

## Publish on GitHub Pages
1. Create a GitHub account, then click **New repository**.
2. Name it `your-username.github.io` (site at `https://your-username.github.io`) or any name such as `profile` (site at `https://your-username.github.io/profile/`). Set it to **Public**.
3. Click **uploading an existing file**, drag in `index.html`, the `css` folder and the `images` folder, then **Commit changes**.
4. Go to **Settings > Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, choose branch `main` and folder `/ (root)`, then **Save**.
5. Wait 1 to 2 minutes and refresh. The live link appears at the top of the Pages screen.
